Strata 是前段时间关注到的一个端侧的推理框架，在单卡上跑起来 100 多 B 的 Qwen 3.8 Flash Next 模型能够跑出来几十上百 tok/s，能正儿八经跑起来一些 agent 任务，这放一年前是完全没法想象的。

平时工作虽然跟大模型 Infra 有关，但是对推理框架直接经手的不多。就想使用 rust 复现一下 Strata 找找手感，家里的游戏电脑上也比较容易调试。有一说一，搞推理主要的门槛还是机器环境太贵，有了上百 B 的这个 size 的模型能用单卡带起来，也是一个了解这部分工作的上手的好路径。

折腾了两个多星期之后勉强能够在自己的机器上和 Strata 跑的性能差不多了。因为预算问题，手里能用到的模型主要是 DeepSeek V4.1 Flash 和 GPT-6.2-Sol，如果氪 Claude 系的模型我猜应该不至于折腾这么久，不过折腾就在过程。用便宜点儿的模型，仍能留有一部分遇到瓶颈、克服瓶颈的乐趣。。。

在本地跑的是 Qwen 3.8 Flash Next 的 Coder 变种，它砍了一半的专家参数，所以总共在七八十 B 左右。性能跑起来大约 Prefill 在 1000 tok/s 左右，Decode 的 TPOT 在 36.8 ms 左右也就是 27.2 tok/s 左右。单纯生成速度还是很够用的。

硬件是 RTX 4070 12GiB 显存，AMD Ryzen 3600，64GiB DDR4 内存。在调试时候发现这个配置对 Local LLM 并不是很理想，如果 CPU 核心更多、有 AVX512、是 DDR5，肯定能跑到更高。

## Qwen 3.8 Flash Next 模型与 Strata

Qwen3.8 Flash Next 模型是一个非常稀疏的模型，总共 125B 的模型参数，大部分都是专家参数，其中激活参数只有 6B，每层只激活 10 个专家。在模型本体之外，还有 51B 的 Ngram embedding 参数。这样总共就接近于 170B 左右。

总共也小 170B，单靠量化的功劳也是不够在消费硬件上跑起来的。不过这个模型有两个好处：

1. 是真的稀疏，专家参数激活的少；
2. Egram 参数量虽然不小，但是不用 load 到内存，每 token 只需要查一次 SSD 即可；

Strata 的思路就是在专家调度上做一些功夫，让显存中只存放相关的、活跃的专家，这样理论上每层 10 个专家，每个专家只有四五兆，即使只有 12GiB 的消费显卡，在显存上也能放得下。不过专家的调度会有一定的预测和 cache 的性质，如果预测失败、cache miss，则在 CPU 上跑这几个 miss 的专家，CPU 上跑两三 B 的激活，也完全跑的过来。这里比较精细的地方就是需要做到 CPU 计算和 GPU 计算两者的 overlap。
